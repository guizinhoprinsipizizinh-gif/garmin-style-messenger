# Garmin Style Messenger

Smartwatch-style messaging interface inspired by Garmin, built with HTML, CSS, and JavaScript.

## Features
- Garmin-inspired smartwatch UI
- Messages list and notifications panel
- Responsive layout for mobile and desktop previews
- Simple JavaScript interactions for clock and navigation

## Run locally
Open `index.html` directly in the browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
